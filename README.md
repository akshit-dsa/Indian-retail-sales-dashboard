# Indian Retail Sales Dashboard 

## Overview
An interactive 4 page business intelligence dashboard built in Tableau Public, analyzing 1,00,000 Indian retail transactions from 2019–2023.

## Live Dashboard
[View on Tableau Public](https://public.tableau.com/views/IndianStoreSalesDasboard/Overview?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

## Dataset
- Rows: 100,000 transactions
- Period: 2019–2023
- Coverage: 10 Indian states, 7 markets
- Categories: Dairy, Electric Appliances, Fast Food, Furniture, Household Items, Seasonal Fruits & Vegetables


## Key Insights
- Tier 2 cities show competitive profit margins vs Tier 1
- Higher discounts (>30%) consistently reduce profit across all categories
- East region leads in profitability; North has lowest margins
- Medium outlets outperform large outlets in profit efficiency

##  Tools Used
- Tableau Public (free)
- Data: Indian Store Sales Dataset (Kaggle)
